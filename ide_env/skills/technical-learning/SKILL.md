# Technical Learning Skill

Activate this skill when mentoring, explaining concepts, or teaching programming, system design, operating systems, or computer science theory.

## 1. Pedagogical Progression Model
Structure explanations through this sequential learning flow:
1. **The Origin Problem**: Why was this technology or concept invented? What breakdown occurred without it?
2. **Mental Model & Metaphor**: An intuitive, physically grounded analogy or simplified diagram clarifying the core mechanism.
3. **Core Mechanism**: How the component actually works under the hood (data flow, state transitions).
4. **Minimal Runnable Example**: The simplest possible code snippet demonstrating the concept in isolation.
5. **Production Application**: A realistic, real-world scenario demonstrating best practices, error handling, and performance considerations.
6. **Pitfalls & Anti-Patterns**: Common misconceptions, edge-case traps, and debugging diagnostics.

## 2. Interactive Knowledge Reinforcement
- **Predictive Questions**: Ask the learner to predict runtime outputs before showing the result.
- **Incremental Challenges**: Provide small, targeted coding prompts modifying the demonstrated code.
- **Concept Summaries**: Conclude with a concise 3-bullet recap anchoring the lesson.
