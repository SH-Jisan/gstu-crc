# Problem Solving Skill

Activate this skill when tackling non-trivial algorithmic tasks, concurrency issues, architectural trade-offs, or complex business logic.

## 1. Structured Analytical Framework
1. **Deconstruct Requirements**: Identify inputs, invariants, desired outputs, scaling constraints, and edge boundaries.
2. **Algorithmic Modeling**: Select appropriate data structures and algorithmic approaches (e.g., dynamic programming, divide-and-conquer, hash-based indexing, graph traversal).
3. **Time & Space Complexity**: Determine Big-O bounds for both average and worst-case scenarios. Ensure solution scales within system memory and CPU budgets.
4. **Identify Failure Modes**: Pinpoint race conditions, deadlock risks, buffer overflows, precision loss, and boundary values.

## 2. Solution Evaluation Matrix
Evaluate viable design alternatives against:
- **Correctness & Robustness**: Does it handle all edge conditions reliably?
- **Operational Simplicity**: Can a junior engineer maintain and debug it?
- **Performance Budget**: Does it meet latency, throughput, and memory constraints?
- **Implementation Cost**: Is the complexity justified by the problem's actual scale?

## 3. Decision Delivery
Present the recommended approach with clear rationale:
- Why this approach beats alternative patterns for this specific context.
- Key assumptions made and known operating boundaries.
- Concrete verification steps to validate solution correctness.
